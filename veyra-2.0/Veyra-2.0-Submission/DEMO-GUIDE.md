# Veyra 2.0 Demo Guide

1. Start the backend.
2. Start the frontend.
3. Open the dashboard.
4. Select a valid location.
5. Submit a forecast-risk request.
6. Show probability, risk category, trust state, and explanation drivers.
7. Show loading and unavailable states.
8. Test an unsupported location such as Atlantis.
9. Demonstrate safe abstention and the reason code.
10. Show model/artifact provenance.
11. Show test and release evidence.
12. Explain the difference between the engineering score and scientific score.
